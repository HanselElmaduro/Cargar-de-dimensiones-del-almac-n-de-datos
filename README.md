# Carga de dimensiones del almacén de datos

Práctica en T-SQL del Sistema de Análisis de Opiniones de Clientes. Carga las seis dimensiones del modelo estrella `analisis_opiniones_dw` con datos de demostración.

- [Guía y scripts SQL](dw/README.md)
- [Evidencias de ejecución en SQL Server](docs/evidencias/dimensiones/carga.txt)

La prueba registró 25 filas en el destino. La segunda ejecución conservó los conteos y registró cero cambios.
